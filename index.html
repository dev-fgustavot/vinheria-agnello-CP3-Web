Checkpoint 03 - Sistema Individual com Objetos, Arrays e Funções de Alta Ordem

🍇 Sistema de Gerenciamento de Vinhos

Este projeto foi desenvolvido para aplicar conceitos fundamentais de JavaScript no gerenciamento de vinhos da Vinheria Agnello.

O sistema utiliza objetos, arrays, funções reutilizáveis e funções de alta ordem para organizar, listar e analisar os dados dos vinhos cadastrados.

As informações dos vinhos são armazenadas diretamente no código JavaScript, respeitando a proposta do Checkpoint 03, sem uso de formulários, DOM ou campos de entrada na página.

⚙️ Funcionalidades Implementadas

  • Array de objetos representando vinhos com nome, tipo, safra e estoque.
  • Adicionar novos vinhos dinamicamente ao catálogo por meio de função.
  • Listar todos os vinhos cadastrados utilizando forEach().
  • Filtrar vinhos com estoque baixo, abaixo de 5 unidades, utilizando filter().
  • Calcular o estoque total da vinícola utilizando reduce().
  • Exibir nomes dos vinhos em caixa alta utilizando map().
  • Exibir os resultados por meio de console.log() e alert().

🧠 Conceitos Aplicados

  • Objetos: cada vinho é representado por um objeto com suas principais informações.
  • Arrays: os vinhos ficam armazenados em uma lista organizada.
  • Funções reutilizáveis: o código foi separado em funções para facilitar manutenção e leitura.
  • Funções de alta ordem: foram utilizadas para percorrer, filtrar, transformar e reduzir dados.

🖥️ Como visualizar os resultados

Todas as análises do sistema são exibidas no console do navegador.

Para abrir o console, pressione F12 ou CTRL + SHIFT + I e acesse a aba Console.

Ao carregar a página, o JavaScript será executado automaticamente. O sistema exibirá alertas e também mostrará no console a lista completa de vinhos, os vinhos com estoque baixo, o estoque total e os nomes em caixa alta.
